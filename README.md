# 라인교육연구소 웹사이트

홈 + 사업소개(전문분야 / 사업영역) 페이지입니다.

## 폴더 구성

```
laain-site/
├─ index.html   ← 웹페이지 (디자인·구조)
├─ data.js      ← 수행이력 데이터 (← 여기만 고치면 됨)
└─ README.md    ← 이 문서
```

## 보는 법

`index.html`을 더블클릭해서 브라우저로 열면 됩니다. (`data.js`가 같은 폴더에 있어야 사업영역 목록이 보입니다.)

## 이력 수정하기 (data.js)

`data.js`를 메모장·VS Code 같은 편집기로 엽니다. 6개 영역이 있고, 각 줄이 사업 하나입니다.

```js
{ year: "2025", title: "사업명 여기", client: "발주처 여기" },
```

- **추가**: 해당 영역 `[ ]` 안에 위 한 줄을 복사해서 내용만 바꾸면 됩니다.
- **수정**: 오타 난 글자를 그대로 고치면 됩니다.
- **삭제**: 그 줄을 지우면 됩니다.
- 줄 끝 **콤마(,)** 와 양쪽 **따옴표("")** 를 빠뜨리지 마세요.
- 영역 이름(`livinglab`, `workshop`, `education`, `forum`, `strategy`, `youth`)은 바꾸지 마세요.

저장하고 브라우저를 새로고침하면 바뀐 내용이 화면에 자동 반영됩니다. 건수(예: "수행사례 보기 (16건)")도 자동으로 다시 셉니다.

## 영역 구분

| 키 | 화면 표시 |
|---|---|
| livinglab | 리빙랩·참여형 문제해결 |
| workshop | 주제별 회의·워크숍 |
| education | 교육·양성과정 |
| forum | 행사·학술포럼·공론장 |
| strategy | 비전·미션·전략 수립 |
| youth | 미래세대·청년 참여 |
